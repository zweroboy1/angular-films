About the Project

A small movie catalog application built with Angular 20 using mock data. The goal is to get hands-on experience with core Angular concepts: components, routing, directives, pipes, and signals.

This project does not use RxJS — all reactivity is built exclusively with Angular Signals.

Features

  • 🎥
    Film Catalog

    Browse all films with poster, title, year, genre, rating and duration.

  • 🔍
    Live Search

    Filter films by title in real time using Angular Signals — no RxJS needed.

  • ❤
    Favorites

    Toggle any film as favorite. The favorites list updates instantly via computed signals.

  • 📄
    Film Details

    Click any card to see full film information on a dedicated page.

  • ⚓
    SPA Routing

    Navigation without page reloads using Angular Router with lazy-loaded components.
